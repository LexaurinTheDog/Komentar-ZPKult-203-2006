# Komentář k zákonu č. 203/2006 Sb., o některých druzích podpory kultury a o změně některých souvisejících zákonů

Otevřený komentář k zákonu o některých druzích podpory kultury — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; veřejné kulturní služby, státní příspěvkové organizace v kultuře, pojištění vypůjčeného majetku, náhrada za vypůjčený předmět, registr umělců, stipendium a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2006-00203_2025-07-01`.
